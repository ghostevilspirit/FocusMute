# 炉石传说版说明 · FocusMute v1.1.0

这个包只做一件事：**炉石传说窗口不活跃时，把炉石的声音关掉；回到炉石窗口，声音自己回来。**

装好就不用管了，没有界面、没有托盘图标、没有弹窗。

---

## 一、「不活跃」是怎么判断的

程序每 400 毫秒看一次：现在最前面的那个窗口，属于哪个程序。

- 最前面是 `Hearthstone.exe` → 判定「聊着炉石」，声音留着
- 最前面是别的程序 → 判定「炉石不活跃」，把炉石这一路声音静音

注意：判断的是**窗口焦点**，不是「有没有被挡住」。比如你开了个半透明窗口盖在炉石上，但焦点还在炉石，那不算不活跃。

---

## 二、什么情况会静音，什么情况不会

| 你的操作 | 声音 | 为什么 |
|---|---|---|
| Alt+Tab 切到浏览器、QQ、微信 | **静音** | 前台窗口换成了那个程序 |
| 点任务栏上别的程序 | **静音** | 同上 |
| 点开始菜单、打开搜索、点系统托盘 | **静音** | 前台窗口变成系统界面 |
| 把炉石最小化 | **静音** | 炉石不再是前台窗口 |
| Win+D 回桌面 | **静音** | 前台变成桌面 |
| Win+L 锁屏 | **静音** | 前台变成锁屏界面 |
| 炉石开着打牌、开包、看结算、在菜单里 | 有声 | 炉石就是前台 |
| 记牌器窗口（Overwolf / Firestone）点到最前面 | 有声 | 这一版把三个 Overwolf 进程算作「还在炉石里」，见下面第四节 |
| 炉石在后台，但你在用其它程序放视频 | 炉石静音、视频正常 | 只静音炉石这一路 |
| 用 OBS、QQ 语音、YY 说话 | 不受影响 | 那些是别的进程的音频，脚本不碰 |

一句话记法：**你眼睛盯着炉石，就有声音；你眼睛看着别处，炉石就没声音。**

## 三、它不会动的东西

- **不改游戏文件**。`Hearthstone` 安装目录、`%LOCALAPPDATA%\Blizzard\Hearthstone\options.txt` 一个字节都不写。战网更新、扫描与修复都覆盖不到这个工具。
- **不改游戏内音量**。你设的 `soundvolume` / `musicvolume` 原样保留，静音是 Windows 层面另加的一层。
- **不影响别的程序**。只操作炉石进程的那一路音频会话。
- **不注入、不挂钩子、不读游戏内存**。所以不会和反作弊打架，也不是 T26 里那种 `0xc0000374` 崩溃的来源。
- **不需要管理员**。装的是当前用户的计划任务。

## 四、这个包预填了什么配置

路径：`%LOCALAPPDATA%\FocusMute\focus-mute.json`

```json
{
  "processes": ["Hearthstone"],
  "mode": "Mute",
  "duckVolume": 0.1,
  "intervalMs": 400,
  "includeOverlay": ["Overwolf", "OverwolfBrowser", "OverwolfHelper"],
  "logMaxKB": 1024
}
```

| 项 | 值 | 意思 |
|---|---|---|
| `processes` | `Hearthstone` | 只盯炉石 |
| `mode` | `Mute` | 失焦时直接静音 |
| `intervalMs` | `400` | 每 0.4 秒看一次，切走基本是即时静音 |
| `includeOverlay` | 三个 Overwolf 进程 | 记牌器（Firestone 跑在 Overwolf 里）窗口点到最前面时，炉石声音照旧 |
| `logMaxKB` | `1024` | 日志满 1 MB 自动翻新一份 |

不用记牌器的用户，可以把 `includeOverlay` 改成 `[]`，行为完全一样，只是少三条判断。

---

## 五、不想完全静音，只想小声

改 `mode` 为 `Duck`，`duckVolume` 填 `0.1`（也就是压到 10%），保存后双击 `restart.cmd`。

它会先把炉石那路静音、再把音量压到 10%，切回来时先恢复音量、再取消静音——这样一个切换不会有「啪」的一声。

## 六、装与卸

装：

1. 解压 zip。
2. 双击 `install.cmd`。装到 `%LOCALAPPDATA%\FocusMute`，加登录自启任务（名字 `FocusMute`），马上生效。
3. 解压出来的文件夹可以删。

卸：

```powershell
uninstall.cmd          # 停看护 + 删自启任务，配置和日志留着
uninstall.cmd full     # 连 %LOCALAPPDATA%\FocusMute 一起删
```

## 七、出问题怎么查

1. 双击 `status.cmd`。看三行：
   - `音频会话`：应该能看到 `Hearthstone(pid=xxxx)`，`静音=True/False`
   - `当前前台`：现在最前面的程序是谁
   - `判定`：`目标失焦 → 静音` 或 `目标活跃 → 保持有声`
2. 双击 `test.cmd`：能听到一次 1.5 秒静音，说明控制通道没问题。
3. 都不对，看日志：`%LOCALAPPDATA%\FocusMute\logs\focus-mute.log`，每次状态变化一行，带时间。

三种常见情况：

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 切出去了但没静音 | 有些全屏设置下系统仍把炉石算作前台 | 先 `status.cmd` 确认「当前前台」是谁；确实是游戏的话，改 `Duck` 模式即可（音量变化比静音更容易感知，也更稳） |
| 炉石没声音但音量条是满的 | 炉石自己的音频会话被点了静音（合成器里） | `test.cmd` 跑一次会自动解除；或 `uninstall.cmd` 后重装 |
| 换了耳机后不生效 | 换默认播放设备后会话重新创建 | 不用管，最多 1 秒自动重新识别 |

## 八、和记牌器一起用

这个静音工具本身不注入炉石，不会引起崩溃。

但记牌器（Firestone，跑在 Overwolf 上）是**注入式**的，炉石历史上出现过 `ntdll.dll` + `0xc0000374` 崩溃，来源就是这类注入。相关的排查记录在本工作区 `工具\炉石\README.md`（T26）。两件事互不影响：静音照常工作，记牌器要不要开是另一个决定。
